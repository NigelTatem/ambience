Ambience 1.3.3 fixes Pip's pixel animation and adds Pip, Ambience's animated pixel-bear guide, and a smoother way to add videos.

- Drop Zone: drag MP4, MOV, or M4V files into it and Pip imports them automatically.
- A replayable, cozy first-run tutorial led by Pip.
- System, light, and dark appearance modes with moss, twilight, and ember accents.

Ambience 1.2.1 adds quick playback controls and a long-loop preset.

- Previous-video and restart-loop buttons beside the playback controls.
- A 10-minute loop preset for long ambience videos.
- Publish-only setup mode so an older installed build can test the in-app update prompt.

Ambience 1.2.0 adds built-in signed updates and a Discover tab.

- Local MP4/MOV wallpapers with audio and adjustable loops.
- Per-video zoom and positioning with a draggable preview.
- Settings for startup, battery usage, storage, and update checks.
- Discover supports resolution selection, source credits, cancellation, and verified downloads. The initial catalog is empty pending approved wallpaper uploads.
